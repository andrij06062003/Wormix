# Wormix Client Files

Place the Wormix 1.05.0 Flash client files here.

Expected folder structure:
wormix-client/
  ├── preloader.swf
  └── vk/
      └── 1.05.0/
          ├── preloader.swf
          ├── Wormix.swf
          └── data/
              └── ... (maps, assets, sounds, etc.)

Once the files are copied into this folder, they are automatically mounted read-only into the relay server.
